# CSV Word Frequency Analyzer

A Java application for analyzing word frequency in CSV files. Parses CSV files, extracts text from specified columns, and counts the frequency of each word.

## 📋 Features

- Parse CSV files with various delimiters (comma, semicolon, tab)
- Count frequency of each word in the text
- Case-insensitive word counting
- Ignore punctuation and special characters
- Configurable columns for text extraction
- Sort results by frequency or alphabetically
- Export results to a new CSV file
- Support for large files with streaming parser
- Multi-language text support (UTF-8)


### Prerequisites
- Java 11 or higher
- Maven (optional, for building)
